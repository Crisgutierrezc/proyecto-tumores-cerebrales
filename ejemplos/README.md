# Imágenes públicas de prueba

Cuatro imágenes de Brain Tumor MRI Dataset, publicado por Masoud Nickparvar en Kaggle (CC BY 4.0). ejemplos.json documenta etiquetas, rutas originales y SHA256. Selección por nombre, sin escoger por acierto. Se prueban manualmente usando la carga de la app.

Fuente: https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset
